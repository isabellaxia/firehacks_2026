The analyst works by filing a strip for every step it takes. Each strip shows the tool it called, what it asked for, and what came back. Blue strips are arithmetic done in Python against the report database — no language model produces a number in this system.

Narratives are confidential voluntary safety reports. Counts, rates and p-values are computed from the database in Python; models read text, name patterns and write prose. This is a hackathon prototype, not an airworthiness or operational safety tool.
